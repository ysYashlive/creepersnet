What's live in this build vs. what needs a backend

This page is a fully working frontend — browsing, cart, account form, and Discord/UPI flows are wired up and simulated so you can see and test the experience.

Three things need a real backend once you deploy this (Nifty and similar static hosts only serve HTML/CSS/JS, they don't run servers):

  • UPI payments — needs a registered payment gateway (Razorpay/Cashfree/PhonePe etc.) and a server to create orders and verify webhooks.
  • Discord verification — needs a Discord OAuth2 app + a small server to exchange the auth code and check guild membership/roles.
  • Hourly email reports — needs a scheduled job (cron, or a service like GitHub Actions/Render Cron) that queries your server stats and sends mail via something like Nodemailer or Resend.

Say the word and I'll write that backend (Node/Express is a natural fit) as a separate deployable service — the frontend here can point straight at it.
